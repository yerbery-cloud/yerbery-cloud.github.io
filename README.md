# Yerbery's Personal Garden 🌿

> 把知识、书页、银幕与远方，慢慢收进同一个地方。

**Personal Website:** `yerbery-cloud.github.io`

这里是 Yerbery 的个人网站源码仓库。

这是一个用来记录学习、阅读、电影与旅行的个人花园。  
相比于传统博客，我更希望它成为一个能够长期积累的空间：保存知识，也保存生活。

---

## ✦ About

网站目前主要由四个世界组成：

### 01 / Learning

记录计算机科学学习、课程笔记与项目实践。

主要内容包括：

- Computer Science
- Algorithms & Systems
- Artificial Intelligence
- Research Notes
- Projects & Experiments

希望把复杂的问题拆开、理解、验证，再整理成可以复用的知识。

### 02 / Reading

记录读过的书，以及阅读之后真正留下来的东西。

内容涵盖：

- 悬疑
- 文学 · 小说
- 文学 · 散文与随笔
- 游阅
- 其他阅读记录

这里不是书籍资料库，而更像是一间安静的 Reading Room。

### 03 / Movies

记录电影、动画以及银幕熄灭之后仍值得回想的画面与情绪。

**Frame · Sound · Memory · Afterglow**

### 04 / Travel

记录走过的城市、路线、天气、照片与旅行片段。

**City · Route · Photo · Summer**

比起完整的旅游攻略，我更希望保存那些真正构成旅行记忆的小瞬间。

## ✦ Tech Stack

This website is built with:

- Hexo 8
- GitHub Pages
- EJS
- Stylus
- JavaScript
- Custom Hexo theme: `yerbery`

---

## ✦ Repository Structure

主要目录：

- `source/_posts/` — 网站文章
- `themes/yerbery/` — 自定义网站主题
- `_config.yml` — Hexo 全局配置
- `package.json` — 项目依赖与运行脚本
- `.github/` — GitHub 相关配置

---

## ✦ Local Development

安装依赖：

```bash
npm install
```

启动本地预览：

```bash
npm run server
```

生成静态网站：

```bash
npm run build
```

部署网站：

```bash
npm run deploy
```
